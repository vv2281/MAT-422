#Mathematical Methods in Data Science (MAT 422)

Coursework from MAT 422 at Arizona State University, Fall 2026.
This repository covers the mathematical foundation of data analysis and 
prediction, including linear algebra, probability, optimization, and newtwork
analysis, with implementations in Python. 

##Tools
Python, Jupyter Notebook, Google Colab
NumPy, pandas, matplotlib
